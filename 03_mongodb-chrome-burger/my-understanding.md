## My Understanding – MongoDB

จากการเรียน MongoDB ทำให้เข้าใจว่า MongoDB เป็นฐานข้อมูลแบบ NoSQL ที่เก็บข้อมูลในรูปแบบของ document แทนที่จะเป็นตารางเหมือน relational database โดย document จะมีโครงสร้างคล้าย JSON และถูกจัดเก็บอยู่ใน collection

MongoDB มีความยืดหยุ่นมากกว่าในเรื่องของโครงสร้างข้อมูล เพราะไม่จำเป็นต้องกำหนด schema ที่ตายตัวเหมือน relational database ทำให้สามารถเก็บข้อมูลที่มีโครงสร้างแตกต่างกันได้ง่ายกว่า

ได้เรียนรู้การเขียน query เพื่อค้นหาข้อมูล รวมถึงการใช้ aggregation pipeline เพื่อประมวลผลข้อมูลเป็นขั้นตอน เช่น การกรองข้อมูล ($match) การจัดกลุ่ม ($group) การเรียงข้อมูล ($sort) หรือการแปลงข้อมูล ($project)

แนวคิดของ aggregation pipeline ทำให้เข้าใจว่าข้อมูลจะถูกส่งผ่านแต่ละ stage ทีละขั้นตอนเพื่อแปลงหรือวิเคราะห์ข้อมูลตามที่ต้องการ

โดยรวมแล้ว MongoDB ทำให้เห็นอีกแนวทางหนึ่งของการจัดเก็บและประมวลผลข้อมูล ซึ่งเน้นความยืดหยุ่นของ document และการประมวลผลข้อมูลผ่าน pipeline
