## My Understanding – PostgreSQL

จากที่ได้เรียน PostgreSQL ฉันเริ่มเข้าใจแนวคิดของ relational database มากขึ้น โดยข้อมูลจะถูกเก็บอยู่ในรูปแบบของตาราง ซึ่งแต่ละตารางจะมีแถวและคอลัมน์ และสามารถเชื่อมความสัมพันธ์กันได้ผ่าน primary key และ foreign key

สิ่งที่ฉันได้ฝึกมากที่สุดคือการเขียน SQL เพื่อดึงและจัดการข้อมูล เช่น การใช้ SELECT เพื่อดึงข้อมูล การใช้ WHERE เพื่อกรองข้อมูล รวมถึง ORDER BY, GROUP BY และ JOIN ที่ช่วยให้เราสามารถจัดเรียงหรือรวมข้อมูลจากหลายตารางได้

การออกแบบฐานข้อมูลก็เป็นอีกเรื่องที่สำคัญ เพราะต้องคิดว่าแต่ละตารางควรเก็บข้อมูลอะไร และควรเชื่อมความสัมพันธ์กันอย่างไร เพื่อให้ข้อมูลไม่ซ้ำซ้อนและสามารถใช้งานได้ง่าย

โดยรวมแล้ว PostgreSQL ทำให้ฉันเข้าใจพื้นฐานของการทำงานกับฐานข้อมูลเชิงสัมพันธ์ และวิธีใช้ SQL ในการดึงและจัดการข้อมูลอย่างเป็นระบบ
